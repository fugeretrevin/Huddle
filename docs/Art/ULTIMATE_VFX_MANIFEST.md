## 4. Runtime Pooling & Quality Tier Controls

- **`MuseDesk.Art.MuseVfxPoolPlayer`:** Pre-warms fixed-size ring buffers (`poolSize`, default `4`) of both `ParticleSystem` instances and 3D spatial `AudioSource` instances on `Awake()` so runtime `PlayEffect(...)` calls allocate zero heap memory.
- **`MuseDesk.Art.SpatialQualityPresetAdapter`:** Maps a single `ArtEffectQualityTier` (`High`, `Medium`, `Low`) uniformly across `CeilingDeploymentVFXController`, `WallHabitatLargePortalVisualController`, `DocumentCourierController`, `MuseVfxPoolPlayer`, and standalone `ParticleSystem` arrays.
  - `High` -> `Full` ceiling VFX + portal/courier particles enabled.
  - `Medium` -> `LowCostNoParticles` ceiling VFX, reduced-motion / paused portal & courier particle systems.
  - `Low` -> `MinimalIrisHalo` ceiling VFX, all optional particles cleared & disabled.
